

ACP ORCA opt 阶段 Hessian 默认行为重构

版本：v1.3 · 2026-07-25 · 状态：评审已整合，待实施

作者：QCcalc Team

影响范围：全部 ORCA geometry optimization 路径（simple / energy / conformer）、CLI、API、scheduler、catalog、前端 wizard、配置文件与测试。NMR 路径暂不纳入（NMR 模块尚未完成开发，后续单独处理）。

一句话目标：ORCA opt 阶段默认不再对 CHON+卤素分子重算 Hessian；含 P/S/Si/B 时默认每 10 步（与旧版一致）；含金属等其他元素时默认每 7 步（较旧值更保守）。用户可在全部 ORCA opt 路径显式指定 auto、关闭或正整数间隔。

已确认的破坏性变更：CLI 完全废弃 --recalc-hess，仅提供 --calc-hess [N|auto] 与 --no-calc-hess。API 字段仍复用 recalc_hess，但语义扩展为 auto | 0 | N | null。

2.1 当前实现

Hessian 重算由 legacy ORCA 接口集中生成，当前逻辑位于 src/cccp/qc/interfaces/orca.py:252-266：

2.2 主要问题

 | 问题 | 影响

 | 默认固定 Recalc_Hess 10 | 轻元素有机小分子承担不必要的解析 Hessian 成本

 | 不能显式关闭 | 用户无法选择 ORCA 默认近似 Hessian + BFGS 更新

 | 不区分元素组成 | 轻元素与含金属/P/S/Si 的体系使用同一默认策略

 | energy 不透传 | src/acp/workflows/energy.py:320-331 无法响应 per-job 配置

 | conformer/NMR 不透传 | frontend levels 中的 hessian 设置无法进入 legacy protocol/engine

 | YAML/Python 分歧 | Python 默认 10；YAML 缺少 recalc_hess

 | 缺少统一校验 | catalog 的 min/max 只约束普通前端输入，不能约束 CLI/API/scheduler

3. 目标与非目标

3.1 目标

CHON+卤素分子默认不输出 Recalc_Hess（仅初始 Hessian，BFGS 更新）。

含 P/S/Si/B 时默认输出 Recalc_Hess 10（与旧版一致，避免回归）。

含金属等其他元素时默认输出 Recalc_Hess 7（较旧值更保守，契合困难势能面）。

recalc_hess 支持 "auto"、0、正整数与 null。

CLI 完全重构为 --calc-hess [N|auto] / --no-calc-hess。

simple、energy、conformer 内部 ORCA opt 全部支持显式控制；NMR 内部复用 ConformerEngine 的 opt 随共享改造一并获得新默认行为，NMR 专属 levels 字段推迟（详见 10.4）。

新增统一解析与校验函数，所有入口行为一致。

新增后端 Hessian preview API，前端不再镜像化学规则。

resolved interval（按分子解析后的实际值）落入 provenance/state，保证 ORCA input 可精确复现。

同步 Python 与 YAML 默认值，修复 recalc_hess 配置分歧。

3.2 非目标

不修改 ORCA CalcFC、NumHess、InitHess 或 TS 优化策略。

不修改 CREST/CENSO/xTB 自身 Hessian 行为。

不实现 SMD + 纯 opt 的 Recalc_Hess Num_N fallback，仅补测试并记录风险。

不扩展 simple workflow 的输入格式；裸 SMILES 仍由 scheduler materialization 处理。

不处理 YAML 与 Python 的 timeout 默认值分歧。

不保留 --recalc-hess 兼容 alias；该决策已确认。

不为 NMR 专属 levels/schema 增加 recalc_hess 字段（NMR 模块未完成开发）；但 NMR 内部复用 ConformerEngine 的 opt 会随本次共享改造获得新默认行为，这是预期且合理的（详见 10.4）。

4. 关键设计决策

 | # | 决策点 | 选择 | 理由

 | D1 | 元素分级 | 轻元素 {C,H,O,N,F,Cl,Br,I}；常见杂原子 {P,S,Si,B}；金属/其他 | 轻元素=有机小分子主体；P/S/Si/B 势能面通常良性，维持旧间隔 10 避免回归；金属体系平坦/复杂势能面，取更保守的 7

 | D2 | 字段模型 | 复用 recalc_hess，接受 "auto" | 0 | N | null | 避免新增持久化字段；旧整数 payload 保持兼容

 | D3 | Auto 语义 | 显式 "auto" 表示立即按元素推断，并忽略 config 中的固定间隔 | 前端 Auto 与后端实际行为一致；CLI 也可强制 auto

 | D4 | 缺失语义 | null/缺失 表示"未指定，跟随 config"；config 默认 "auto" | 保留配置文件作为站点级默认值的能力

 | D5 | 覆盖范围 | simple、energy、conformer 的 ORCA opt 全部显式支持；NMR 专属 levels 推迟，但其内部 opt 默认行为随共享改造生效 | 消除同类工作流行为不一致；NMR 显式控制待模块完成开发后补齐

 | D6 | 默认间隔（分级） | 自动启用时：轻元素 0；P/S/Si/B 10；金属/其他 7 | 15 缺乏科学依据；P/S/Si/B 维持旧值避免回归；金属按 ORCA 对困难势能面建议取更保守值。该阈值为待收敛基准校准的初值，后续可调

 | D7 | 工具位置 | acp/chem/composition.py | 按评审结论保留在 ACP chemistry 层；ORCA 中采用 lazy import 降低 import-time 反向依赖

 | D8 | 前端 preview | 后端接口返回真实解析结果 | 同时感知 config、explicit value 与批量结构，避免前后端规则漂移

 | D9 | CLI 兼容 | 完全废弃 --recalc-hess | 用户已确认；文档和迁移说明必须明确

5. 字段语义与校验

5.1 recalc_hess 取值

 | 输入 | 归一化结果 | 含义 | ORCA 输出

 | 缺失 / null / 空字符串 | None | 未指定，读取 config | 由 config 决定

 | "auto"（大小写不敏感） | "auto" | 强制按元素推断，忽略 config 固定值 | 轻元素不输出；P/S/Si/B 输出 Recalc_Hess 10；金属/其他输出 Recalc_Hess 7

 | 0 或 "0" | 0 | 显式"仅初始 Hessian"（不重算） | %geom 中不输出 Recalc_Hess

 | N 或 "N"，1–1000 | N | 显式间隔 | Recalc_Hess N

 | 负数、大于 1000、float、bool、其他字符串 | 报错 | 非法 | 不生成输入文件

兼容性：旧 payload 中的正整数继续有效；旧 payload 未指定字段时继续走 config。旧 payload 不可能合法包含 0，因为旧 catalog 下限为 1，因此 0 可安全作为新“关闭”语义。

5.2 解析优先级

job/API/CLI 显式值
    │
    ├─ "auto" → 元素推断（忽略 config）
    ├─ 0      → 仅初始 Hessian（不重算）
    └─ N      → 每 N 步
         │
         ▼ 仅当显式值为 null/缺失
config.optimization_control.recalc_hess
    │
    ├─ "auto" → 元素推断
    ├─ 0      → 仅初始 Hessian
    └─ N      → 每 N 步
         │
         ▼ 仅当 config 也为 null/缺失
元素推断（分级）：
  轻元素 {C,H,O,N,F,Cl,Br,I} → 0
  常见杂原子 {P,S,Si,B}      → 10
  金属/其他                  → 7

5.3 校验规则

统一由 normalize_recalc_hess() 解析，禁止各层重复手写。

整数字符串可接受并归一化为 int；非整数字符串报错。

拒绝 bool，避免 True 被 Python 当作 1。

拒绝所有 float，包括 20.0，避免静默截断。

CLI 的 --calc-hess 只接受 auto 或 1–1000；"仅初始 Hessian（不重算）"必须使用 --no-calc-hess。

6. 元素分类与解析工具

6.1 新模块

新建 src/acp/chem/composition.py。

"""Molecular composition and Hessian default utilities."""
from __future__ import annotations

import re
from dataclasses import dataclass

# --- Element classification (D1) ---
LIGHT_ELEMENTS: frozenset[str] = frozenset({"C", "H", "O", "N", "F", "Cl", "Br", "I"})
HETEROATOM_ELEMENTS: frozenset[str] = frozenset({"P", "S", "Si", "B"})

# --- Graded default intervals (D6) ---
HETEROATOM_DEFAULT_INTERVAL = 10   # matches legacy 10, avoids regression
HEAVY_ELEM_DEFAULT_INTERVAL = 7     # conservative for metals / flat PES
MAX_RECALC_HESS_INTERVAL = 1000     # safety cap (~ effectively never)
AUTO_RECALC_HESS = "auto"

def normalize_recalc_hess(value: object) -> int | str | None:
    if value is None:
        return None
    if isinstance(value, bool):
        raise ValueError("recalc_hess must be 'auto', 0, or an integer interval")
    if isinstance(value, int):
        if value < 0 or value > MAX_RECALC_HESS_INTERVAL:
            raise ValueError("recalc_hess interval must be between 0 and 1000")
        return value
    if isinstance(value, str):
        text = value.strip().lower()
        if not text:
            return None
        if text == AUTO_RECALC_HESS:
            return AUTO_RECALC_HESS
        if re.fullmatch(r"\d+", text):
            return normalize_recalc_hess(int(text))
        raise ValueError("recalc_hess must be 'auto', 0, or an integer interval")
    raise ValueError("recalc_hess must be 'auto', 0, or an integer interval")

def classify_symbols(symbols: list[str] | tuple[str, ...]) -> tuple[set[str], set[str]]:
    """Return (heavy_elements, triggering_elements) sets for diagnostics.

    ``heavy_elements`` are all non-light elements present;
    ``triggering_elements`` excludes the benign heteroatom class (P/S/Si/B).
    """
    if not symbols:
        raise ValueError("symbols list is empty")
    normalized = [str(symbol).strip().capitalize() for symbol in symbols]
    if any(not symbol for symbol in normalized):
        raise ValueError("symbols must not contain empty values")
    heavy = {s for s in normalized if s not in LIGHT_ELEMENTS}
    triggering = heavy - HETEROATOM_ELEMENTS
    return heavy, triggering

def is_light_element_molecule(symbols: list[str] | tuple[str, ...]) -> bool:
    heavy, _ = classify_symbols(symbols)
    return not heavy

def default_recalc_hess_for_symbols(
    symbols: list[str] | tuple[str, ...] | None,
) -> int:
    if symbols is None:
        raise ValueError("symbols are required when recalc_hess is 'auto'")
    heavy, triggering = classify_symbols(symbols)
    if not heavy:
        return 0
    if not triggering:  # only P/S/Si/B beyond light set
        return HETEROATOM_DEFAULT_INTERVAL
    return HEAVY_ELEM_DEFAULT_INTERVAL

def resolve_recalc_hess(
    explicit: object = None,
    configured: object = None,
    symbols: list[str] | tuple[str, ...] | None = None,
) -> HessianResolution:
    """Resolve recalc_hess to a concrete interval + provenance metadata."""
    source = "config"
    for candidate, src in ((explicit, "explicit"), (configured, "config")):
        normalized = normalize_recalc_hess(candidate)
        if normalized is None:
            continue
        source = src
        if normalized == AUTO_RECALC_HESS:
            interval = default_recalc_hess_for_symbols(symbols)
            reason = "auto"
            break
        interval = int(normalized)
        reason = "explicit_interval" if interval > 0 else "explicit_off"
        break
    else:
        # both explicit and configured are null/missing → element inference
        interval = default_recalc_hess_for_symbols(symbols)
        reason = "auto"
        source = "config"

    heavy, triggering = classify_symbols(symbols) if symbols else (set(), set())
    return HessianResolution(
        interval=interval,
        source=source,
        reason=reason,
        heavy_elements=sorted(heavy),
        triggering_elements=sorted(triggering),
    )

@dataclass(frozen=True)
class HessianResolution:
    """Resolved Hessian policy with full provenance for audit/replay."""
    interval: int
    source: str          # "explicit" | "config"
    reason: str          # "explicit_interval" | "explicit_off" | "auto"
    heavy_elements: list[str]
    triggering_elements: list[str]

    @property
    def enabled(self) -> bool:
        return self.interval > 0

设计要点（v1.3）：

resolve_recalc_hess() 返回 HessianResolution dataclass，携带 source/reason/heavy_elements/triggering_elements，供 ORCAInterface 直接写入 provenance，保证可复现（见 7.5）。

分级默认集中在 default_recalc_hess_for_symbols()，后续按收敛基准数据校准时只改常量，不触动调用方。

HessianResolution 用 @dataclass(frozen=True)；因 from __future__ import annotations，resolve_recalc_hess 注解中的前向引用在定义期不报错，运行时 dataclass 已在模块作用域就绪。

7.3 lazy import（带模块级缓存）

为降低 legacy → ACP 的 import-time 反向依赖，在 orca.py 中使用局部 lazy import，并加模块级单例缓存避免 conformer 批量场景下每帧重复 import（模式与现有 _resolve_method_meta() 一致）：

_RESOLVER = None

def _get_resolver():
    global _RESOLVER
    if _RESOLVER is None:
        from acp.chem.composition import resolve_recalc_hess as _r
        _RESOLVER = _r
    return _RESOLVER

def _resolve_recalc_hess_lazy(
    explicit: object,
    configured: object,
    symbols: Optional[list[str]],
):
    return _get_resolver()(
        explicit=explicit,
        configured=configured,
        symbols=symbols,
    )

7.4 symbols 透传

_write_input() 已接收 symbols，只需传给 _build_input_blocks()。生产路径中 optimize/optfreq 都会经过 _write_input()，因此 symbols 必然可用。直接调用 _build_input_blocks("opt") 且需要 auto 推断但未传 symbols 时必须报错；显式 0/N 不需要 symbols。

7.5 日志与 provenance

自动启用时记录触发元素列表和最终间隔，不记录完整原子列表，避免大分子日志噪音：

Auto Hessian recalc enabled: interval=7, non-light elements=Fe, Cl

provenance 持久化（v1.3 新增，保证可复现）：auto 的最终 interval 依赖具体分子元素，同一 recalc_hess="auto" 在不同分子上下发不同 ORCA input。因此必须把解析后的实际值落入审计产物。在 _write_input 写完 *.inp 后，同目录写一个 sidecar JSON：

# <calc_dir>/conf_000_opt.inp  →  <calc_dir>/conf_000_opt.hessian.json
{
  "interval": 7,
  "enabled": true,
  "source": "auto",
  "reason": "auto",
  "heavy_elements": ["Cl", "Fe"],
  "triggering_elements": ["Fe"],
  "input_value": "auto",
  "config_value": "auto",
  "resolved_at": "2026-07-25T12:00:00Z"
}

实现：_record_hessian_resolution(out_dir, resolution, input_value, config_value)。同时 append 一条 event 到 state.json 的 provenance 流（若 workflow/scheduler 上下文可用）。scheduler 的 artifacts.py 应将该 sidecar JSON 纳入 job artifacts 采集，使其随结果回传。

为何必须持久化：计算化学平台对"输入文件可精确复现"是硬要求。只记输入 "auto" 无法重建实际下发的 %geom 块，含金属体系尤其敏感（interval 7 vs 10 会改变优化轨迹与最终构象能量，进而影响 Boltzmann 权重）。

9.1 参数定义

9.2 argparse 类型

auto：返回字符串 "auto"。

1–1000：返回 int。

0、负数、float、其他字符串：触发 argparse.ArgumentTypeError。注意 --calc-hess 0 会报错，"仅初始 Hessian"必须用 --no-calc-hess（避免与 API 的 0 语义混淆）。

--calc-hess 无值时通过 const="auto" 表示强制元素推断。

9.3 kwargs 构造

calc_hess = getattr(args, "calc_hess", None)
no_calc_hess = getattr(args, "no_calc_hess", False)

if no_calc_hess:
    kwargs["recalc_hess"] = 0
elif calc_hess is not None:
    kwargs["recalc_hess"] = calc_hess

必须使用 getattr()，因为 _build_simple_method_kwargs() 也被 singlepoint/frequency 调用，而这些 parser 没有 hessian 参数。

关键澄清（v1.3）："NMR 推迟"仅指 NMR 专属 levels/schema 的 recalc_hess 字段。NMR 内部复用 ConformerEngine 的 opt 会随本次共享改造一并获得新默认行为，这是预期且合理的。

调用链实证：

acp run nmr
  └─ workflows/nmr.py:426  run_cccp()
       └─ workflows/conformer.py  ConformerEngine.run()
            └─ core/engine.py:628  _run_shared_dft_handoff()   # ext/full/lite/zero 共用
                 └─ core/engine.py:689,1197  self.opt_interface.optimize()
                      └─ qc/interfaces/orca.py  _build_input_blocks()  ← 本次改造点

默认行为无法推迟：真正改变全局行为的是 config 默认 10 → "auto" 与 orca.py 的 resolve 逻辑。这两处落地后，NMR 内部 conformer opt 在 CHON 分子上将从 Recalc_Hess 10 变为不输出，与 conformer/energy 完全一致。

显式控制推迟：NMR 的 frontend levels（confsearch.dft_opt 等）本次不新增 recalc_hess 字段；待 NMR 模块完成开发后单独补齐 schema、converter、CLI 联动。

不矛盾：engine 改造是共享的，NMR 只是"不暴露字段"，不是"保留旧默认"。文档与 changelog 必须明确这一点，避免评审者误以为 NMR opt 仍走旧逻辑。

风险记录：NMR 的构象 Boltzmann 权重依赖 opt 后能量；默认行为变更会改变 NMR 谱预测结果。含金属体系的 NMR 任务在本次变更后会使用 interval 7（较旧值 10 更保守），需在 release note 提示。

代码回滚：改动集中，可按 workflow 分 commit 回滚。

行为回滚：将 config 中 optimization_control.recalc_hess 设为 10，可恢复旧的"默认每 10 步"计算行为（对所有 workflow 包括 NMR 内部 opt 生效）。

数据兼容：数据库无 schema 变更；历史整数 payload 继续有效。

运行中任务：已生成的 ORCA input 不受影响。

provenance：本次新增的 *.hessian.json sidecar 不影响旧 job（旧 job 无此文件，按"输入即真相"处理）。

18.1 迁移说明

复现性敏感场景（v1.3 新增）：若你的部署/benchmark 依赖固定的 Recalc_Hess 10 行为，升级前在 config/defaults.yaml 或本地 override 中显式写入以锁定旧行为，避免默认值变更静默改变历史结果：
optimization_control:
  recalc_hess: 10   # pin legacy default; remove to opt into auto inference
此设置对 simple/energy/conformer/NMR 内部 opt 全部生效（NMR 显式字段控制仍待其模块完成）。

 | 旧写法 | 新写法

 | --recalc-hess 5 | --calc-hess 5

 | 无法"仅初始 Hessian" | --no-calc-hess

 | 无法强制元素推断 | --calc-hess auto 或裸 --calc-hess

 | 不传参数 | 不传参数，继续跟随 config

 | 依赖默认 Recalc_Hess 10（未显式配置） | 显式 recalc_hess: 10 锁定；否则升级为分级 auto
