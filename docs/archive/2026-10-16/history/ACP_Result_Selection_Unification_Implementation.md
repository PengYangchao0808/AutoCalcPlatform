# ACP 选点展示与任务结果统一：实施与验收记录

日期：2026-10-01。对应 `ACP_Result_Selection_Unification_Plan.md`。本轮已修改业务代码，保留开始前的未提交改动；未提交 Git、未重启在线服务、未连接真实计算节点执行化学计算。

## 已落地

- 编辑目标由稳定 `input_id` / `source_uid + version_id` 绑定。新增勾选对象获得输入编辑焦点，移除前项不会改写其他对象。详情旧响应不能重建正在编辑的表单，相同行再次点击保留草稿；名称框区分本次输入与来源库名称，行菜单可直接重命名。
- 索引刷新在事务内替换发现字段，保留结构名、标签、人工评价、角色修订与回收站状态。退出新策略的历史发现记录标记缺失，用户信息保留。
- OPT 几何在成功阶段立即登记。Batch、顺序计算、TS Mode、NMR 前置构象均保留已成功阶段，后续属性失败不删除成功几何。OPT 收敛、角色和 TS 验证分别展示；不放宽 TS Mode launch gate。
- 统一策略拒绝多帧 XYZ、无效元素、缺原子和非有限坐标。IRC 接受 `irc_endpoint`，路径作为轨迹保留；逐方向判断完成，不把达到最大迭代数当作端点成功。
- PES 新生成结果、历史推荐投影、候选接口、能量图、结构查看器和 Batch 导入采用 `manual_only`。人工保存/确认的选点继续使用；曲线与轨迹不删除。
- Confsearch 来源与重算输出使用全部正式发布构象，rank 排序；纯 FREQ/SP 不增加自动结构。
- `previous_outputs[]` 带任务、产物、路径、版本、校验和、attempt 与方向。蓝色输入随当前输入变化；紫色输出、灰色上次输入、预览轮廓分别展示，固定区保留分页/筛选外输入和全部旧输出。旧输出需显式选择替换，自己的旧输出允许原地重算；Batch 替换同步到最终提交条目。
- 原地清理前，将输出保存为内容寻址对象及按 attempt/entry 区分的历史别名，保留原输入和批量输入快照。校验或读盘失败阻断排队；清理后可读历史来源，旧路径缺失时可回退到历史别名。
- 来源分类排序发生在服务端分页之前，覆盖实际 catalog 的全部活动工作流；频率缺失/失败结构及已验证 TS 按上下文优先。角色、出处、计算状态、用户标签独立呈现。
- 结果页区分执行状态、自动结构数量及验证状态。远程统一使用 RemoteStructureCache，正式构象也下载；目录待同步与几何待下载不会误报为确定的零结构。
- 历史补登记器只恢复带对象标识、明确收敛状态和有效终态几何引用的 OPT 轨迹；支持 dry_run，幂等执行。本地失败/取消任务索引重建自动接入；远程没有同步到充分证据的历史任务不会猜测补登记。既有纯属性来源仍可解析用于旧输入，新来源列表隐藏重复几何。

## 验收

全量回归（`pytest -m "not slow"`）：**4597 passed，8 skipped，16 deselected，0 failed**。Bruker 可选依赖 `nmrglue` 不存在，相应用例未执行；deselected 数还包含已有名称匹配。

`manual_only` 与阶段对齐改造后，若干旧断言仍按旧契约编写（PES 自动推荐、BatchOptimize 六阶段 `prepare/…/finalize`、Confsearch rank1-only 与多帧 ensemble、v1 enrichment 对象同一性、前端 CSS 无版本号链接），已按新契约更新。`test_from_confsearch_manifest` 属改造遗漏，已一并修正。

重算快照校验保留：旧输出几何非法时仍阻断。但原输入或远程结果不可读不再阻断重算，只是跳过该次快照，避免核心「重算」被非致命读取失败锁死。lineage 只读快照测试改为冻结后台执行后再比较，消除启动期 `updated_at` 写入竞态。

Python 编译、修改模块的 Ruff F 检查、三个独立前端模块及工作台内嵌脚本语法检查通过。回归包括真实管理器的原地重算、清理后读取快照/旧路径，以及快照失败不清理、不排队。

真实浏览器使用 `tests/fixtures/selection_ui.html` 的隔离验收页，加载实际候选详情组件和输入协调器；输入表单及勾选回调取自当前工作台源码。已操作验证：A→B 快速切换、输入中返回延迟详情、重复点击 B、勾选 B 后改名只更新 B、删除前项并改变索引后仍继续编辑 B。该结果是组件交互验收，不等同于截图对应的在线服务验收。

## 数据生命周期与上线边界

历史别名位于任务 `.structure_history/`，内容寻址对象位于 run_root `.structure_snapshots/objects/`。普通原地重算不清理历史目录；永久任务清理沿用原任务清理规则。快照没有新增自动回收机制，避免错误回收已引用几何。

后台索引启动时重建终态任务发现字段；人工组织元数据不重置。历史 OPT 补证据接口为 `backfill_successful_optimizations(task_root, workflow, dry_run=True)`。实际生产数据与远程节点未在本轮连接或迁移，需在服务使用本轮代码后根据同步证据执行重建。真实 ORCA/xTB/LSF 集成和在线完整创建/重算交互尚未进行现场验收。
