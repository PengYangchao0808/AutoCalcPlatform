# ACP 振动模式查看器 UX 优化方案

**版本**：v1.0（2026-09-11）
**状态**：待实施
**范围**：结构查看器中的频率模式浏览、虚频判断、位移箭头与动画控制
**设计目标**：不横向挤压分子画布；字体统一；模式浏览紧凑、均匀、清晰；TS 证据与当前选择不混淆。

## 1. 结论

将当前右侧振动抽屉改为结构画布下方的 **可收起底部停靠面板**。振动数据存在时，结果摘要栏显示明确入口：

```text
[虚频 1] [振动模式 87]  → 点击展开底部面板
```

底部面板不覆盖分子，展开后由布局系统压缩 3D 画布高度并触发 3Dmol resize；关闭后画布恢复完整高度。用户切换模式时不关闭面板、不改变相机。

## 2. 当前界面问题

1. 340px 右侧抽屉持续压缩横向画布，大分子被迫缩小或偏移；抽屉下半部又存在大量无效留白。
2. “振动模式”标题、虚频摘要、TS 判断、模式列表和动画控制全部纵向堆叠，缺少清晰主次。
3. 87 个模式塞在 220px 高的窄列表中，零模、虚频和普通模式混排，浏览效率低。
4. 字号在 10px、11px、12px及更大的提示文字间频繁变化；中文、数字和单位的字形与基线不统一。
5. 当前虚频摘要使用“当前选中模式”的频率。选中正频 `42.44 cm⁻¹` 后仍显示“虚频 1/87、42.44 cm⁻¹”，语义错误。
6. 模式列表和下方模式下拉框重复表达同一件事，占用空间并增加操作歧义。
7. “频率数量符合一阶鞍点”“仍需检查振动方向及 IRC”“阈值”等文字权重接近，视觉上像连续正文，而不是结论、提示和依据。

## 3. 推荐布局

### 3.1 收起状态

默认只在结果摘要栏保留紧凑状态：

```text
TS 优化结果   [TS] [已完成]   [虚频 1 · -419.46 cm⁻¹]   [振动模式 87 ▴]
```

- 有显著虚频：红色描边状态胶囊；
- 无虚频：绿色或中性色“无显著虚频”；
- 多个虚频：琥珀/红色“虚频 3”；
- 没有数据：不显示入口，不保留空面板；
- 数据加载中：入口内显示小型 loading，不改变摘要栏高度。

### 3.2 展开状态

```text
┌ 振动模式  #6  -419.46 cm⁻¹  [虚频]  [一阶鞍点证据]       [—] [×] ┐
├──────────────┬──────────────────────────────────┬────────────────┤
│ TS 证据       │ 模式浏览                          │ 位移显示       │
│ 显著虚频 1    │ [虚频 1] [有效模式 80] [全部 87] │ 箭头/动画/组合 │
│ 阈值 -50      │ ──频率谱或紧凑模式轨道────────  │ 振幅 0.05 Å    │
│ 建议检查 IRC  │ 当前模式的频率与 IR 强度          │ 播放  速度  相位│
└──────────────┴──────────────────────────────────┴────────────────┘
```

桌面宽屏建议三列：

- TS 证据区：`220–250px`；
- 模式浏览区：占剩余空间，作为视觉主体；
- 动画控制区：`320–360px`。

面板默认高度 `236px`，允许在 `180–340px` 间拖动；最大不超过中央工作区高度的 42%。面板高度按任务保存，首次仍使用默认值。

### 3.3 响应式

- 中央工作区宽度 ≥ 1200px：三列布局；
- 800–1199px：TS 证据与动画控制位于上行，模式浏览占下方整行；
- < 800px：改为可滚动底部 sheet，模式浏览优先，控制项折叠；
- 任何宽度下都不重新使用固定右侧抽屉。

## 4. 模式浏览优化

### 4.1 默认分类

将模式分为三个筛选标签，而不是一次显示全部：

- `虚频 1`：显著虚频和其他负频；TS 任务默认打开；
- `有效模式 80`：过滤平移/转动零模后的正频模式；
- `全部 87`：用于完整核查。

零模不删除，只在默认视图中折叠为一项：`平移/转动零模 6 个`。展开“全部”后仍保持 ORCA 原始 mode index。

### 4.2 频率谱

宽屏下用紧凑频率谱代替狭窄长列表：

- 横轴为 `cm⁻¹`，零点明确标出；
- 负频位于零点左侧，用红色；正频位于右侧，用蓝灰色；
- 当前模式用 2px 高亮线和实心节点；
- hover 显示 `#mode、频率、IR 强度`；点击选择并即时更新箭头/动画；
- 对高频密集区域采用抽样刻度，不隐藏模式本身；
- 提供键盘左右键切换相邻模式。

若首期不实现图形频率谱，可先采用横向自适应模式网格，每项固定 `144×32px`，但仍应保留三类筛选和当前模式高亮。

### 4.3 去除重复控件

- 删除“完整列表 + 模式 select”双重选择；
- 桌面端以频率谱/模式轨道为唯一主选择器；
- 小屏端才使用 select 作为降级控件；
- 当前模式信息只在面板标题显示一次。

## 5. TS 信息语义修正

必须把“任务总体结论”和“当前模式”拆开：

- 总体：`显著虚频 1 个，符合一阶鞍点的频率数量条件`；
- 当前：`#7  42.44 cm⁻¹ · 正频`；
- 最显著虚频：始终显示真正的最低虚频，如 `#6  -419.46 cm⁻¹`；
- 只有当前模式本身是负频时才显示“虚频”标签；
- 阈值作为次级说明：`显著虚频阈值 ≤ -50 cm⁻¹（默认）`；
- `仍需检查振动方向与 IRC` 使用一行轻提示，不与判定标题同字号。

默认选择顺序：最负的显著虚频 → 最负的其他负频 → 第一个有效正频。用户选择正频后，TS 总体结论不变，但标题必须同步显示“正频”。

## 6. 控制区重排

动画控制统一为两行网格：

```text
显示  [箭头] [动画] [组合]       振幅  ─────●──  0.05 Å
播放  [▶ 播放/暂停]              速度  [1.0×]  [反转相位]
```

- 标签列统一宽度 40px；所有控件高度 30px；
- 分段按钮等宽，不随中文长度跳动；
- 播放是唯一主按钮，其余保持次级样式；
- 播放中用状态点和“播放中”表达，不使用整行黄色斜体文字；
- “动画播放中，编辑已暂停”放在控制区底部的单行琥珀提示；
- 振幅值、速度和频率全部使用 tabular numbers，避免数字变化时跳动。

## 7. 字体与视觉规范

### 7.1 字体角色

在全局 token 中明确两套字体，不在组件内随意使用 `monospace`：

```css
--font-ui: "IBM Plex Sans", "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif;
--font-mono: "IBM Plex Mono", "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

- 中文标题、按钮、说明：`var(--font-ui)`；
- mode index、频率、IR 强度、振幅：`var(--font-mono)`；
- `button/input/select` 强制 `font-family: inherit`；
- 若项目不打包 IBM Plex 字体文件，应删除不可保证存在的首选字体，避免不同机器产生不可控回退；若保留，则将 Sans/Mono 的 WOFF2 一并本地化。

### 7.2 字号层级

只使用四级：

| 用途 | 字号/行高 | 字重 |
|---|---|---|
| 面板标题、当前频率 | `14px / 20px` | 600 |
| 正文、按钮、模式项 | `12px / 18px` | 400–500 |
| 字段标签、次级信息 | `11px / 16px` | 500 |
| 状态胶囊 | `10px / 16px` | 600 |

不使用全大写中文，不用斜体表达状态。单位统一为 `cm⁻¹`、`km·mol⁻¹`、`Å`，负号使用一致字形并让小数点对齐。

### 7.3 间距与颜色

- 采用 4px 基础网格：区块间距 12px，控件间距 8px，内部 padding 8/12px；
- 面板只保留一层外边框，不给每段都套深色卡片；
- 红色仅用于负频和错误，蓝色用于当前选择，绿色用于满足条件；
- 普通模式使用中性文字，不用高饱和底色；
- 当前模式高亮使用细边框和浅背景，避免整行重色块。

## 8. 状态与交互

- 打开面板、切换模式、拖动振幅时保留 3D 相机；
- 面板展开/收起及拖动高度后调用 `viewer.resize()`，但不重复 `zoomTo()`；
- 切换任务、结构 entry 或标签时停止动画并恢复平衡几何；
- 播放时禁止几何编辑，停止后恢复；
- 切换筛选时若当前模式被过滤，仍在标题保留当前模式，并提供“显示所在分类”；
- 加载失败只在底部面板显示一行错误，不撑出空白区域。

## 9. 实施建议

### P0：布局与语义

1. 将 `sv-drawer-vibration` 替换为 `sv-vibration-dock`，挂在 3D 画布下方；
2. 摘要栏新增虚频/振动模式入口；
3. 拆分“显著虚频总体结论”和“当前模式”，修复正频被标成虚频；
4. 默认选择最负显著虚频；
5. 统一字体 token、字号、控件高度和单位格式；
6. 展开/收起时触发 3Dmol resize 并保持相机。

### P1：模式浏览

1. 增加虚频/有效模式/全部筛选；
2. 折叠六个平移/转动零模；
3. 实现频率谱或横向模式轨道；
4. 删除桌面端重复 mode select；
5. 增加键盘切换、tooltip 和当前模式自动可见。

### P2：响应式与打磨

1. 可拖动高度及状态持久化；
2. 中屏双行、小屏 bottom sheet；
3. 加入视觉回归与真实 3Dmol 尺寸测试；
4. 检查中英文、正负号、上标和单位基线。

## 11. 验收标准

- 展开振动模式后，分子画布不再横向缩窄；关闭后恢复原高度；
- 当前任务默认选中 `#6 -419.46 cm⁻¹`，且只有该模式显示“虚频”；
- 切换到 `#7 42.44 cm⁻¹` 后，标题显示“正频”，总体仍显示“显著虚频 1 个”；
- 87 个模式可通过三个筛选快速浏览，六个零模默认折叠；
- 1920px 以上为三列均衡布局，无大面积空白；1440px 不发生文字或控件重叠；
- 所有中文使用 UI 字体，所有科学数值使用统一等宽字体和 tabular numbers；
- 控件高度一致，模式列表/频率谱、TS 证据和动画控制边缘对齐；
- 面板展开、切换模式和拖动高度不重置相机；
- 箭头、动画、组合、振幅、速度、相位反转和播放/编辑互斥功能全部保留。
