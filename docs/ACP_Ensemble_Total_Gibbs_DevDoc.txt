1. 需求理解与数学基础

1.1 目标

构象搜索的核心目的除了获得构象系综外，是获得系综总自由能：

计算方式 = 构象的 ΔG（相对排名第一）加上玻尔兹曼分布引入的熵；

可只用排名第一的构象完成该计算（见 §1.2 推导）；

计算时必须注意单位（全流程统一 Hartree，见 §1.3）。

1.2 数学推导（rank1-only 数学化简）

构象系综（混合体系）的总吉布斯自由能：

p_i     = exp(−ΔG_i / kT) / Σ_j exp(−ΔG_j / kT)，   ΔG_i = G_i − G_min
G_total = Σ_i p_i·G_i  +  RT·Σ_i p_i·ln p_i              （完整混合式）
        = G_min + Σ_i p_i·ΔG_i + RT·Σ_i p_i·ln p_i

利用 p_i = exp(−ΔG_i/RT)/Z 且 p_1 = 1/Z（ΔG₁ = 0）：

Σ_i p_i·ΔG_i = −RT·Σ_i p_i·ln p_i + RT·ln p_1
─────────────────────────────────────────────
G_total = G_1 + RT·ln p_1      （只依赖排名第一构象的 G 与其玻尔兹曼权重）

混合修正量 RT·ln p_1 = Σ p_i·ΔG_i + RT·Σ p_i·ln p_i 恒为负值（熵稳定化）。两式数学上严格相等（同一 G 表下），工作流一用完整混合式、工作流二用 rank1 式，并在实现中交叉校验（容差 1e-8 Ha）。注意：该等价性仅是数学化简，不保证理论水平一致性——工作流二以 xTB/CENSO 级权重表驱动 p₁、以精细 DFT G₁ 进入总自由能时，结果仍为近似，误差估计 ±0.5–1.5 kcal/mol（见 §3 与 §12）。

1.3 单位约定

 | 量 | 单位 | 常量 / 换算 | 代码位置

 | G（Shermo g_conc / CENSO gtot） | Hartree | — | energy.py:434（gibbs = g_conc）

 | 玻尔兹曼常数 k_B | Ha/K | 3.166811563e-6 | energy.py:48；censo_backend.py:65

 | Hartree → kcal/mol | — | × 627.5094740631 | acp/core/models.py:19（HARTREE_TO_KCAL）

 | 混合熵 S_mix | Ha/K·分子 | −k_B·Σ p ln p；×627.509… → kcal/(mol·K) | 新模块（§4）

⚠️ 新模块统一从 acp.core.models 导入 HARTREE_TO_KCAL，避免在第三个位置重复定义该常量（既有 anti-pattern：models.py 与 cccp/utils/constants.py 双定义）。

1.4 数值验证示例

两构象，ΔG₂ = 1.0 kcal/mol，T = 298.15 K
kT = 3.166811563e-6 × 298.15 = 9.4418e-4 Ha = 0.5925 kcal/mol
p₁ = 1 / (1 + exp(−1/0.5925)) = 0.8442
G_total = G₁ + kT·ln(0.8442) = G₁ − 0.101 kcal/mol
完整式核对：ΣpΔG + RT·Σp ln p = 0.1558 + 0.5925×(−0.4330) = −0.1007 kcal/mol ✓（±1e-4 舍入差）

4. Step 1：新增 ensemble_thermo.py（核心计算模块）

新建 src/acp/workflows/ensemble_thermo.py（约 130 行，纯函数 + 汇总 dataclass，无 QC 依赖）

energy.py 已 1156 行（AGENTS.md 标注"candidate for future split"），总自由能计算放入独立模块，便于单测与后续复用。

 | 符号 | 签名 | 说明

 | mixing_entropy | (weights: list[float]) -> float | S_mix = −k_B·Σ p ln p（Hartree/K·分子）；配套 s_mix_kcal_per_mol_kelvin() / t_s_mix_kcal_per_mol() 换算

 | ensemble_total_gibbs | (rank1_gibbs: float, weights: dict[str, float] | list[float], temperature_k: float) -> float | G_total = G₁ + k_B·T·ln p₁（工作流二；p₁ 为排名第一权重）

 | ensemble_total_gibbs_from_values | (gibbs_values: list[float], temperature_k: float) -> float | 完整混合式 Σ p·G + RT·Σ p ln p（工作流一）；内部与 rank1 式断言一致性（容差 1e-8 Ha）

 | EnsembleThermoSummary | 新建 @dataclass | method（dft_table/censo_table_rank1）、T、G_total（Ha + kcal/mol）、G₁、p₁、S_mix、T·S_mix、population_coverage、逐构象表（G_i/ΔG_i/p_i）；to_dict() / write_json(path)

# 模块内单位常量（复用既有定义，不新增）
from acp.core.models import HARTREE_TO_KCAL        # 627.5094740631
_K_B_HARTREE_PER_KELVIN = 3.166811563e-6           # 与 energy.py:48 同步

G_total = rank1_gibbs + _K_B_HARTREE_PER_KELVIN * temperature_k * math.log(p_1)

4.1 边界条件

空权重表 / 全零权重：返回 rank1_gibbs（无混合熵修正），不抛异常；

p_1 ≤ 0（或非有限）：告警并返回 rank1_gibbs，不钳制为极小值——钳制 1e-12 会注入约 −16 kcal/mol 的伪修正（kT·ln 1e-12）；p_1 > 1：钳制为 1.0（无修正）；

非归一化权重输入：调用方负责归一化（CENSO boltzmann_weights() 与 _boltzmann_weights 均已归一化）。

12. 风险与注意事项

 | 风险 | 说明 | 缓解

 | 截断偏差（工作流一） | DFT 表只覆盖 ≥99% 累计集合：截断 + 重归一化使 p₁′ = p₁/P_A 变大、尾部构象熵贡献丢失，两个效应均使混合熵被低估、G_total 被高估约 RT·ln(1/P_A) ≈ +0.006 kcal/mol（P_A=0.99） | ensemble_thermo.json 记录 population_coverage（= 选中集合在全系综表中的累计权重），如实披露
