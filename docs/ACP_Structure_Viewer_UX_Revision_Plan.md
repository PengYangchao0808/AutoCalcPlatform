# ACP 结构查看器与能量轨迹界面 UX 修订方案

**版本**：v2.0（2026-09-11）  
**状态**：待实施，作为当前界面重排的最新依据  
**优先级**：P0 视觉与信息架构修复 → P1 多结果交互 → P2 细节完善  
**继承范围**：保留既有 `structure_viewer_v1`、`normal_modes_v1`、轻量几何编辑、虚频动画、叠合与远程缓存能力；本轮重点修正信息架构和默认展示语义。

振动模式面板的后续视觉与交互优化，以 [ACP 振动模式查看器 UX 优化方案](ACP_Vibration_Viewer_UX_Optimization_Plan.md) 为准。

## 1. 结论

结构查看器改为 **结果优先、画布优先、工具按需出现** 的单画布工作区：

- 打开任务首先展示该任务最可信的结果，而不是文件、输入结构或结构目录；
- 永久移除结构查看器左侧的固定结构列表；多构象、多候选和多帧改为紧凑结果切换器或底部可收起条带；
- 永久移除右侧固定检查器；核心信息放入一行结果摘要，测量、编辑、振动和来源详情通过上下文抽屉按需打开；
- “能量与轨迹”成为与结构查看器平级的独立工作区，不再嵌套在结构查看器三栏布局中；
- 保留任务队列右侧全局栏，但不再在中央工作区内重复常驻检查器。

核心原则可概括为：**打开即见结果，中央区域只服务当前任务的主要证据。**

## 2. 当前问题与定位

### 2.1 能量与轨迹被错误地二次压缩

当前 `#viewer-energy` 位于 `.sv-layout` 的中间列，而 `.sv-layout` 固定为
`220px 1fr 260px`。能量页自身又使用“能量图 + 结构预览”的双列布局，因此实际形成：

```text
结构列表 220px | 能量图 + 结构预览 | 结构检查器 260px | Workbench 全局任务栏
```

这就是新版本与旧版观感相差明显的主要原因：结构模块的导航和检查器侵入了能量模块，主图面积、留白比例和视觉中心全部被破坏。

### 2.2 结构列表表达了实现结构，而非用户任务

任务通常有一个明确的“当前最重要结果”。左侧列表把数据源和条目集合直接暴露给用户，即使只有一个条目，也可能因为存在命名 group 而继续显示。它重复了文件树和任务语义，并占用稳定的 220px。

### 2.3 固定检查器信息密度过低

检查器无论是否有能量、虚频或测量数据都占用 260px。状态、来源、空振动提示与少量编辑按钮纵向铺开，造成中央画布缩小、右侧大片空白。许多信息还是任务详情栏已经表达过的内容。

### 2.4 “默认选择正确”不等于“用户知道这是结果”

后端 resolver 已按正式结果优先选择条目，但 BatchOptimize 展示名直接继承
`product.label`，正式结果仍可能被标成 `input (...)`。数据来源是 formal result，界面却看起来像输入结构，结果语义被原始标签污染。

## 3. 新信息架构

### 3.1 顶层工作区必须彼此独立

```text
中央工作区
├─ 结构查看器：结果摘要 + 全尺寸 3D 画布 + 可选结果条带/工具抽屉
├─ 反应路径：路径专用界面
├─ 能量与轨迹：全尺寸图表 + 可折叠节点结构预览
└─ 波函数：波函数专用界面
```

各标签只共享 `geometryStore`、当前任务和当前 frame/entry 状态，不共享 DOM 布局。特别是 `#viewer-energy` 必须移出 `.sv-layout`，成为标签宿主的直接子工作区。

### 3.2 结构查看器默认布局

```text
┌ 结果：优化终态 ▼   TS · 已收敛   E = ...   虚频 1 个     [详情] ┐
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                         3D 主画布                              │
│                                                               │
├───────────────────────────────────────────────────────────────┤
│ [构象 1/12] [◀] [▶] [播放]   （仅多结果/多帧时出现，可收起）   │
└───────────────────────────────────────────────────────────────┘
```

- 顶部保留现有样式、测量、截图等紧凑工具栏；新增“结果摘要条”。
- 3D 画布默认获得除工具栏和必要播放条以外的全部面积。
- 单结果任务不出现结构导航控件。
- “详情”打开右侧覆盖式抽屉，不改变画布永久布局；关闭后画布立即恢复全宽。

## 4. 打开任务时的结果语义

### 4.1 统一优先级

```text
正式 RESULT 结构
  > 工作流规范化最终结果
  > 失败任务最后有效结构
  > 运行中最新稳定快照
  > 计算输入（只在任务本身不改变几何或无其他可用结果时）
```

选择任务后自动加载 `default_entry_id`，不要求用户再点文件树或结构列表。若正式结果存在，界面不得以 `input`、原始文件名或内部 product id 作为主标题。

### 4.2 面向用户的命名规则

| 情形 | 主标题 | 辅助说明 |
|---|---|---|
| Batch/OPT 成功 | `优化结果` / `TS 优化结果` | `正式结果 · 已收敛` |
| Batch/OPT 失败 | `最后有效结构` | `优化未收敛 · cycle N` |
| SP | `单点能计算结构` | `几何未改变` |
| Frequency | `频率计算结构` | `几何未改变 · 可查看振动模式` |
| Confsearch | `最低能构象` | `构象 1/N · Boltzmann xx%` |
| PES | `推荐 TS 点` 或 `已确认 TS 点` | 未确认推荐必须显式标注 |
| IRC | `IRC 路径中心/当前帧` | `正向或反向 · frame N` |
| 运行中 | `最新计算快照` | `非最终结果` |

原始 `product.label`、路径和 product id 只放在“来源详情”中，不能控制主标题。

### 4.3 输入/结果对照

输入结构不再占用列表位置。对于会改变几何的任务，在摘要条提供轻量切换：

- `结果`（默认） / `初始`；
- 可选“叠合比较”，复用现有 overlay/RMSD；
- 返回结果页时始终恢复用户最后选择，但首次打开固定为结果。

## 5. 多构象、多候选与多帧

不再使用永久左侧列表，按结果类型采用不同的紧凑表达。

### 5.1 Confsearch

- 默认展示 rank 1；摘要条显示 `构象 1/N`、相对能量、Boltzmann 权重；
- 点击 `构象 1/N` 打开下拉面板，可按排名、能量或权重筛选；
- 需要连续浏览时展开底部构象条带，条目包含 rank、ΔG 和横向 Boltzmann 条；
- 条带默认收起，高度上限 88px，不遮挡或永久缩窄画布。

### 5.2 PES

- 默认展示最高优先级的已确认点；无确认点时展示推荐 TS；
- 使用 `候选 N/M` 切换器，TS/INT 和“未确认”作为紧邻标题的徽标；
- 候选详情（推荐理由、置信度、扫描坐标）在详情抽屉中显示。

### 5.3 优化、扫描与 IRC 轨迹

- 采用底部帧控制条和时间/反应坐标滑杆；
- 不把每一帧展开成结构列表；
- 能量图点选帧后更新当前结构，结构页的前后帧操作也更新共享选中状态。

### 5.4 BatchOptimize 多项目

- 顶部使用 `项目 N/M` 下拉切换；
- 每项显示 TS/INT、完成/失败和虚频警告；
- 单项目任务不显示项目选择器。

## 6. 检查器改为按需工具抽屉

### 6.1 常驻摘要只保留高价值信息

摘要条允许显示：结果名称、角色、可信状态、当前序号、关键能量、Boltzmann 权重、虚频警告。缺失字段直接不显示，不产生“无数据”占位块。

### 6.2 抽屉内容按上下文生成

- 点击原子/测量：打开“测量与编辑”，只显示当前键长、键角或二面角及修改控件；
- 存在 normal modes：打开“振动模式”，显示频率列表、箭头/动画、振幅与速度；
- 点击“来源”：显示 formal result、文件引用、revision 和兼容/远程状态；
- 点击“更多”：显示导出、另存结构资产、以此结构新建计算、叠合等低频动作。

抽屉建议宽度 320–360px，覆盖在画布上方，默认关闭。切换任务、切换标签或完成操作后按明确规则关闭；不以空壳形式常驻。

## 7. 能量与轨迹工作区修订

### 7.1 版式

- 从 `.sv-layout` 移出 `#viewer-energy`；进入能量标签时结构列表、结构检查器和结构播放条均不参与布局；
- 主能量图是视觉主体，默认使用可用宽度的约 70%；节点结构预览与节点信息合并为一个约 30% 的紧凑侧栏；
- 提供“专注曲线”按钮，可一键收起节点侧栏，使图表占满中央工作区；
- 窄屏改为图表在上、节点详情在下，不横向压缩主图；
- 删除与 Workbench 右侧任务详情重复的状态大卡片和冗余标题，状态只保留为小徽标。

### 7.2 交互

- 点选能量节点即时更新右侧小型结构预览和数值详情；
- 提供“在结构查看器中打开”动作，切换到结构标签并加载该帧；
- 结构预览无 geometry 时只显示一行提示，不保留空白 3D 容器；
- 选点、框选、平移、标注与重置工具保留，但合并低频工具，避免工具栏换行；
- 保留 PES 人工选点能力，确认状态放在图表标题区，不另建大面积状态区。

## 8. 实施批次

### P0：恢复正确视觉层级与结果语义

1. 重构 Workbench 标签 DOM，使 structure、energy、path、wavefunction 成为平级工作区；
2. 去掉结构页固定左右栏，建立全宽画布和结果摘要条；
3. 将检查器改为默认关闭的覆盖抽屉；无数据 section 不渲染；
4. 统一 Batch/simple 等条目的展示名称，正式结果不得显示为 `input`；
5. 恢复能量页“主图 + 紧凑节点预览”，增加专注曲线模式；
6. 保留所有现有数据契约和化学功能，避免本轮同时重写 resolver/API。

### P1：多结果的紧凑导航

1. 实现构象/候选/批项目下拉切换器；
2. 实现可收起构象条带及 Boltzmann 可视化；
3. 优化轨迹、scan、IRC 统一使用底部帧控制条；
4. 实现输入/结果切换及叠合入口；
5. 完成能量图与结构页选中状态的双向同步。

### P2：体验与响应式完善

1. 键盘导航、焦点返回、抽屉 Esc 关闭和 ARIA；
2. 保存每任务的视图、抽屉和结果切换状态，但首次打开仍遵守结果优先；
3. 大体系和长轨迹性能策略、列表/条带虚拟化；
4. 中文/英文文案及 1100px、1440px、超宽屏视觉回归。

## 10. 验收标准

### 结构查看器

- 打开已完成 OPT/Batch 任务，一次目录请求后直接显示正式最终结构；主标题不含 `input`；
- 单结果任务没有结构列表、项目选择器或空检查器，3D 画布占满内部可用宽度；
- 12 个构象默认显示 rank 1，Boltzmann 可见，但多构象导航不形成固定侧栏；
- 无振动数据时不显示振动空块；有虚频时摘要出现警告，点击后才打开模式抽屉；
- 测量/编辑、来源详情和导出均可达，关闭抽屉后画布恢复全宽。

### 能量与轨迹

- `#viewer-energy` 不再是 `.sv-layout` 的后代；能量标签中不可见结构列表和结构检查器；
- 桌面宽屏下主图获得中央工作区至少 65% 的宽度，专注曲线模式达到 100%；
- 节点结构预览存在时不超过工作区约 35%，无结构时自动折叠；
- 工具栏在 1440px 中央可用宽度下不发生多行挤压；
- 点选节点、打开结构页、返回能量页时选中 frame 保持一致。

### 回归保护

- 虚频方向、轻量几何编辑、撤销/重做、另存资产、overlay/RMSD、远程 pending-fetch 均保持可用；
- 文件树手动打开 XYZ 仍可作为临时结构，但不会覆盖任务结果的默认语义；
- 老任务和退役工作流继续只读展示，不因布局重构改变后端合同。

## 11. 本轮明确不做

- 不重写 `structure_viewer_v1` 或 `normal_modes_v1`；
- 不增加完整分子搭建、原子/键增删、力场优化等重编辑能力；
- 不把所有任务文件重新包装为结构条目；
- 不用更大的检查器承载任务详情，任务级信息继续留在 Workbench 全局右栏；
- 不以更多卡片或装饰弥补信息不足，优先减少常驻区域和重复信息。
