ACP CENSO 集成重构 — 开发文档

概述

由于现有构象搜索阶段的构象生成存在明显缺陷，本次重构引入 CENSO（Commandline ENergetic SOrting，Grimme 组系综精炼程序包）作为构象系综生成的核心引擎，落地两个新工作流：

  • ensemble（构象生成）：直接使用 CENSO 包生成带能量排序与 Boltzmann 权重的构象系综，默认预设 censo-light（文献 CENSO-light 配方，Mészáros et al., JCTC 2024）。
  • energy（构象能量）：在 ensemble 基础上对 rank1 构象追加高级精炼——高精度几何优化（默认开启）+ 高级 DFT 单点（ωB97M-V）+ 同级热修正，输出单个精炼构象（rank1，文献 CENSO-light/zero 语义）；仅 censo-default 预设输出系综（CENSO Part3 原生 99% Boltzmann 截止）。

文献CENSO-zero — 最经济的 rank-1 协议

阶段行为
1. 搜索CREST（GFN2-xTB，iMTD-sMTD，6.0 kcal/mol 窗口）→ xTB 优化的构象系综
2. 排序选择按 xTB 能量排序，仅取 rank1（xTB 最低构象）
3. 精炼仅对 rank1：B97-3c 几何优化 → ωB97M-V/def2-TZVPP 单点（RSH//GGA）→ 热修正取 xTB//xTB 级 mRRHO
输出单个精炼构象 + 其自由能；系综其余构象仅用于 ΔGconfrel 估计
成本/精度MAE 0.9 kcal/mol，MAX 10.5；相对 CENSO-default 提速 30–40×；开销≈一次 CREST + 单构象 DFT 流程
适用快速探索、多态反应机理中各态的廉价初筛（论文推荐配合 GPU 加速 xTB）

文献CENSO-light — 通用构象分析推荐协议（本次默认）

阶段行为
1. 搜索CREST（GFN2-xTB，6.0 kcal/mol 窗口）→ xTB 优化的构象系综
2. 排序选择对 xTB 优化几何做 GGA（B97-3c）单点排序——完全不做系综级 DFT 几何优化；按 GGA 电子能确定最低构象
3. 精炼仅对 GGA rank1：B97-3c 几何优化 → ωB97M-V/def2-TZVPP 单点（RSH//GGA）→ xTB//xTB 级 mRRHO 热修正
输出单个精炼构象 + 自由能；系综 GGA 排序用于 ΔGconfrel
成本/精度MAE 0.6 kcal/mol，MAX 6.0；相对 CENSO-default 提速约 10×；论文结论"仅优化最低构象即可可靠估计整个系综的几何弛豫能"
适用通用构象分析（论文原话"ideal for general-purpose conformational analysis"）；成本仅约为"完全忽略构象分析"的 3 倍

文献CENSO-default — Grimme 漏斗（Part0–Part3）

阶段行为
Part0 预筛对 xTB 系综做 GGA//xTB 排序，4.0 kcal/mol 阈值截断
Part2 系综优化幸存构象做 GGA 级几何优化，按 GGA//GGA 能量 2.5 kcal/mol 阈值再截断
Part3 精炼对 Part2 系综做 RSH（ωB97M-V）单点，按 99% Boltzmann 布居和截断
输出DFT 优化后的精炼系综 + Boltzmann 权重（ensemble 输出，非 rank1）
成本/精度MAE 0.2 kcal/mol；成本约为参考 brute-force 的一半
适用需要整个系综的性质（NMR、光谱等）；或最终能量用高精度（波函数）方法时必须使用

文献CENSO-brute-force — 参考真值

CREST 全部构象 → 全系综 GGA 优化 → 全系综 RSH 单点。作为基准真值，无工程价值，不实现。

2. 文献依据：RTCONF55-16K 要点

RTCONF55-16K 基准集含 55 个反应、16000+ DFT 优化构象（含 ISOL24 异构化与 MOBH35 有机金属反应），用于系统评估构象分析协议的成本-精度权衡。对本次设计有直接约束力的结论：

  • 忽略构象分析的代价：反应自由能 MAE = 2.6 kcal/mol，MAX = 20.5 kcal/mol（r39）——构象处理是必需品而非可选增强。
  • CENSO-light 成本-精度最优点：避免全系综 DFT 优化，仅对最低构象做高级精炼；MAE 0.6 kcal/mol，成本仅为 CENSO-default 的 1/10，仅为"忽略构象"基线的 3 倍。
  • 热修正级别不敏感：ΔGconfrel 在 xTB//xTB 级已足够准（MAE 0.3 kcal/mol），升级级别无显著改善——支持"高级电子能 + xTB mRRHO"的组合公式。
  • 几何弛豫能的系综近似："仅优化最低能量构象即可可靠估计整个系综的几何弛豫能"——支撑 energy 工作流免系综 DFT 优化的设计。
  • CENSO-default 的适用边界：仅当最终能量用高精度波函数方法、或需要全系综性质（NMR、光谱）时才值得其成本。
  • 用途级联：多步机理研究中，各态先用 CENSO-zero/light 定位决速态，再对关键态用 CENSO-default 精炼。
✅ 设计落点：ensemble（默认 censo-light）服务"需要系综"的下游（NMR 等）；energy 服务"需要准确相对自由能"的常规场景；两者共用同一 CensoBackend 与解析契约。
ℹ️ CREST 随机性与可重复性：CREST 的 iMTD-sMTD 搜索具有随机性（不同运行可能产出不同构象系综）。RTCONF55-16K 文献基准测试中未特别控制随机种子，单次运行即作为标准流程。本设计沿用文献做法：默认不设置种子，保持 CREST 原生随机行为。用户若需严格可重复结果（如论文 supplementary data），可通过 CREST 的 -seed <int> 参数固定随机种子（经 YAML crest.seed 或 CLI 传递）。

解析规则：

  • 最终 part 判定：按 refinement → optimization → screening → prescreening 顺序找第一个存在的 N_PART.json。
  • 几何与该 part 的 N_PART.xyz 按 CONF# 对齐（xyz 帧名 = CONF#，数目与 JSON data 键一致；不一致即报 CensoParseError）。

6.3 rcfile 生成器

每次运行在 censo/censo2rc 生成完整 rcfile（模板见附录 A）。要点：

  • [paths] 写入 executables.orca.path / executables.xtb.path 的绝对路径——远程节点路径与 ACP Server 不同，rcfile 必须在运行侧生成（天然满足：backend 代码运行在远程节点）。
  • [general]：temperature、evaluate_rrho=true、sm_rrho=gbsa（无 COSMOtherm）、solvent（ACP 溶剂名 → CENSO 关键字映射表，utils/solvent_maps 扩展）、gas_phase、balance=true、ignore_failed=true、imagthr/sthr 沿用现有 mrrho_settings。
  • part 段按预设填写（见第 7 章）；未启用 part 的段仍写出但不被校验。

6.4 高级 SP 字段注入：per-run 模板文件 + HOME 隔离

rcfile 原生键只覆盖 func/basis/sm/threshold，无法表达现有 single_point level 的全部字段（aux_basis / ri_approximation / grid / scf_convergence / dispersion 补充项，以及 DLPNO-CCSD(T) 的 %basis 辅助基组块）。为此引入 CENSO 模板文件机制（官方特性：{part}.{prog}.template，含 {main} / {geom} 占位符，rcfile 中 template = True 启用）：

  • 官方约束：模板只能从 $HOME/.censo2_assets/ 读取——这是 per-user 全局路径，并发作业会互相踩踏。
  • ACP 方案：subprocess 环境注入 HOME={censo_dir}/home，把"用户 home"重定向到 per-run 隔离目录；CensoBackend 在 {censo_dir}/home/.censo2_assets/refinement.orca.template 写入本次作业的高级块（%basis aux、%scf 收敛、网格、RI 近似等），模板正文形如： 
    {main}
! Grid4 NoFinalGrid
%scf ConvForced true end

{geom}
  • 未被用户覆盖的字段不写模板（template = False），保持 CENSO 默认行为；--levels 出现任一高级字段时才启用。
  • 模板注入同时适用于 screening.orca.template（screening SP 的高级字段）。
  • 安全：模板内容仅由 ACP 字段白名单生成，不允许用户自由文本注入（防止 ORCA 输入注入）。

6.5 mRRHO 计算链（含新几何）— 强制一致性规则

⚠️ 强制规则（v7 定稿，不可配置）：几何优化与频率计算的方法/基组必须一致。凡启用高精度（DFT）几何优化（默认 opt 阶段，--no-opt 关闭，或 censo-default 的 Part2），mRRHO 数据来源一律为同方法同基组的频率计算（ORCA freq → Shermo）。未启用 DFT 优化的路径（--no-opt 廉价路径）则为 xTB 几何 + xTB Hessian（同为 xTB 级，一致性天然成立）。两条路径各自严格一致，仅级别不同。

6.5.3 ZPE 缩放因子（ZPE factor）

ZPE 缩放因子问题（谐振近似系统误差的经验修正）在两条路径中均已显式处理，语义不同：

路径ZPE 来源缩放因子机制默认值与自由度
opt 关（--no-opt）xTB SPH（GFN2-xTB Hessian）CENSO --scale 频率缩放因子（写入 rcfile 映射）。GFN-xTB 频率不缩放是上游惯例：mRRHO 误差主导项是低频处理（sthr/imagthr）而非 ZPE 谐振误差；构象间相对量系统性相消；SPH 文献基准即 unscaled默认 1.0；YAML 高级键 censo.scale 可覆盖（不进 catalog/UI 字段，避免噪音）

  • 决策注记（否决方案）：曾考虑"rank1 优化几何回填 screening 系综 → 全幸存者混合 refinement"（保留 90% 系综输出且仅优化 rank1）。否决理由：① 同一排名混入两种几何级别（r2SCAN-3c vs xTB），能量一致性受损；② 需三次 CENSO 调用 + 几何手术，复杂度违背"避免过度设计"原则；③ 文献结论支持"仅 rank1 弛豫即可代表系综几何弛豫能"，无必要回填。另：v5/v6 的"第二次 CENSO 调用 --optimization --refinement"与 thermo_mode 可配置项均被 v7 取代（原因：CENSO 的 Part2 mRRHO 只能是 xTB 级，不满足 opt/freq 同级一致要求）。
  • 成本提示：rank1 优化+同级频率成本 ≈ 单构象 DFT opt + 一次 Hessian（数十分钟级）；censo-default 的同级频率仅落在 99% 截止后的最终少数幸存者上。系综级全 DFT 频率不做（成本不可承受，文献亦证实无必要）。
  • 预设表同时落地两处并保持同步：acp/backends/censo_backend.py 内置 _PRESETS dict（权威源，随代码同步到节点）与 config/defaults.yaml 的 censo: 展示段（便于用户查阅/覆盖）。覆盖链：CLI --preset > YAML censo.presets.<name> > 内置。
  • B97-3c 为 ORCA 复合方法关键字（! B97-3c SP），无显式 basis——CENSO 以 func 直传 ORCA 主行，无需 basis 键。
  • refinement.func/basis 默认 wb97m-v/def2-tzvpp（文献 RSH 级 + 现有协议默认 basis）；仅是默认值——用户可经 §10.1 的完整字段集覆盖（含 DLPNO-CCSD(T)、辅助基组、色散、RI、溶剂、网格、SCF 收敛）。
  • -n 1 语义（--no-opt 路径）：CENSO 仅读取输入系综前 1 帧；CREST 输出帧序按 xTB 能量升序 → 等价于 xTB rank1（CENSO-zero 文献语义）。注意：默认 opt-on 路径下，censo-zero 不经 CENSO CLI，由 ACP 直接编排 ORCA opt→freq→SP→Shermo（详见 §8 D6）。

8. 与文献的偏差说明

#偏差文献做法本设计理由 / 影响
D1精炼几何级别RSH//GGA：rank1 先 GGA 优化，再 ωB97M-V 单点默认 RSH//r2SCAN-3c（opt 开启，与文献 RSH//GGA 等价，r2SCAN-3c 为 GGA 级复合法）；--no-opt 关闭后降级为 RSH//xTB（廉价路径，偏离文献）v9 决策：默认路径严格对齐文献 RSH//GGA 语义（rank1 经 r2SCAN-3c 优化 + 同级频率 → RSH SP）。用户显式 --no-opt 可走廉价路径。文献表明 rank1 弛豫可代表系综几何弛豫能。D1 偏差在默认路径下已消除
D2热力学来源xTB//xTB mRRHO（SPH）按 opt 状态强制二选一（v7，不可配置）：opt 开（默认）= DFT//DFT（ORCA freq 同方法同基组 + Shermo）；opt 关 = xTB//xTB（CENSO 内部 SPH，与文献一致）有意升级：默认路径采用严格 opt/freq 一致性（DFT 级热修正），成本增加一次 Hessian 计算。opt 路径的 Shermo 产物（.sum 文件）与 ACP 传统格式一致。文献表明 xTB 级 ΔG 差异已足够准（MAE 0.3 kcal/mol），但 DFT 级提供更严格的一致性保证。详见 §1D 对比流程图
D3溶剂模型ALPB(xTB) + CPCM(DFT)，DCM默认气相；可配 GBSA(xTB sm_rrho) + SMD/CPCM(ORCA)可配置参数：与现有 ACP 协议一致，默认气相。无 COSMOtherm；CENSO 的 ORCA 路径原生支持 SMD。溶剂选择由用户根据体系需求配置。
D4CREST 窗口6.0 kcal/mol沿用协议默认（GFN2，可配）建议 energy 默认 6.0 对齐文献；ensemble 可收紧
D5censo-zero 执行路径CENSO -n 1 --refinement（CENSO 软件内部完成 RSH SP）不经 CENSO CLI：xTB rank1 直通 → ACP 直接编排 ORCA opt→freq→SP→Shermo路径不同，结果等价：最终能量表达式 RSH//GGA 相同，但由 ACP 而非 CENSO 执行。原因：opt-on 默认路径需要 DFT 级热修正（ORCA freq + Shermo），CENSO 无此原语。详见 §1D.2 对比流程图
