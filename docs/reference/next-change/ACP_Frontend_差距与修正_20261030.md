# ACP 新旧界面差距与本轮修正

日期：2026-10-30。范围：依据当前工作区源码静态核对；本轮不是完整升级验收。

后续更新：用户明确优先面板与布局配置后，已实现固定三区域的可视化组合、比例、隐藏、恢复默认与刷新恢复。最新差异和本轮实测见 [布局修正复核](ACP_Frontend_Review_Layout_Remediation_20261030.md)。下表保留为此前切片的历史状态，任务配置等业务缺口仍存在。

| 能力 | 经典工作台 | Next 当前状态和目标差距 |
|---|---|---|
| 任务配置 | 结构输入、工作流、方法、资源、预览与提交向导 | 本轮增加服务端现役目录和直达经典向导的入口；新工作区内尚无完整可编辑草稿、预检、审批和提交，跨页不传当前项目或结构。 |
| 任务管理 | 搜索、分组、筛选、批量操作、详情、文件及日志 | Next 只有只读任务列表和本轮新增的详情摘要；完整筛选、操作、工件和日志尚未迁移。 |
| 结构 | 结构编辑、查看、测量及轨迹等 | Next Viewer 仅部分只读结构功能；多格式、测量、轨迹等尚未达到旧版覆盖。 |
| 研究和 Agent | 旧页面有研究及证据组件 | Next 有研究只读面板，真实记录端到端和 DSH 会话、工具事件、审批交互仍须验证。 |
| 工作区 | 单页布局、可调面板 | Next 有三种固定配方与共享焦点，未完成可视化布局配置、独立模块完整生命周期及布局恢复验收。 |
| 架构及发行 | 旧链对接现有服务 | Next 消费既有 client，不能据此认定 ACP 2.0 的安装、身份权限、真实模型和 LSF 联调已通过。 |

本轮补充 `task-config` 目录面板和 `exec-detail` 摘要，经典向导链接通过显式 hash 打开现有向导，仍由原链处理配置与提交。未迁移用户草稿或焦点。详情按项目、任务及 attempt 防止迟到响应覆盖；实际刷新和工件读取尚需完成。

既有 UI-00—UI-03A 收口记录的“已交付”仅可理解为其限定的首片实现，不代表本表中的功能对等或整个目标完成。上述缺口关闭前不能宣称新界面已完成可视化配置。
