# ACP 新前端复核与布局修正

日期：2026-10-30。复核基线：HEAD `484764f6`，包含工作区已有未提交改动。用户确认本轮优先“面板与布局配置”。

## 结论

新 UI 目前是可运行的模块化只读工作台首片，尚不是老工作台的功能替代品。三工作区和几个模块的存在、测试通过，都不能证明完整配置、研究交互和 ACP2 发行目标已经完成。最明显的使用退步是：老 UI 的高密度任务操作、参数向导和分析能力，在 Next 中被较空的只读面板或跨页链接取代。

本轮补齐固定三区域的可视化面板组合与布局保存。没有将完整任务配置、DSH 接入或生产发行标为完成。

对照方案：用户目录中的 `ACP_2.0_前端同步升级开发方案_20261029.md`（审核修订版），尤其 §3.5、§4.2—4.6 和 §7；仓库 UI-00、UI-01、UI-03A 收口记录只作为历史声明，未重跑的历史证据不当成本轮实测。

## 本轮实现与边界

- `shell/layout-preferences.js`：版本化、白名单布局偏好；主区域必选、模块去重、尺寸范围约束；只保存工作区、模块和比例。
- `shell/layout-editor.js`：可键盘操作的原生对话框、布局预览、三区域选择、比例滑块和默认恢复。选择已占位置的模块时交换位置；取消不写入。
- `recipes.js` / `layout-manager.js`：继续消费原配方，动态补底区；已有面板 DOM 迁移、隐藏暂停、排除隐藏面板的命令查找；避免 Viewer 复制。
- `bootstrap.js` / `i18n.js` / `next/index.html` / `shell.css`：入口、最后工作区恢复、中英文本和响应式样式；修复 SVG 空白和折叠空间。
- 原有未提交工作保持原状；本轮未编辑科学执行、Services、后端 API、生产服务或发行清单。

模块配置范围限于五个已提供面板。名称为“任务配置”的面板仍只有目录和经典向导入口；布局编辑器不会声称该模块具有完整配置能力。偏好存储不加载外部脚本，也不授予模块业务权限。

## 后续优先级

1. 布局深化：按模块 descriptor 落实完整能力协商，补关闭/重开资源基线与安装后路径验收；如需自由停靠，再扩展布局模型，不把固定区域当无限画布。
2. 功能对等：将旧任务列表筛选、状态门控操作、工件和日志接入同一面板；任务配置按工作流逐个验证字段和提交结果，不能重新实现科学默认值。
3. 研究交互：核实真实 DSH 版本和公开接口后接入工具时间线、参数差异和统一审批；无接口时保留只读降级。

本轮可验收结论为“面板与固定区域布局可视化配置已落地”，不扩大为“新 UI 已替代老 UI”或“ACP2 全面联调通过”。
