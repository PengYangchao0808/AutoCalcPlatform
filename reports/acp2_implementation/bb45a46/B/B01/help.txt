ACP 2.0 runtime acceptance harness skeleton (acp2.acceptance.v1). Validate receipts/samples, print exact dry-run commands, or execute a registered scenario. Scenario bodies are owned by B04a..B25b.

options:
  -h, --help            show this help message and exit
  --scenario SCENARIO   registered B scenario ID
  --controller CONTROLLER
                        existing Controller URL to connect to; the harness
                        never starts one
  --launch LAUNCH       MCP stdio launch manifest path
  --fixture FIXTURE     scenario request/fixture JSON path
  --out OUT             output directory for run receipt + summary
  --timeout TIMEOUT     override the registry timeout (seconds)
  --check-only PATH     validate an existing summary.json or receipt (tool
                        check, not PASS)
  --phase PHASE         registered phase for the scenario
  --dry-run             print exact commands and create no DB/process/job
  --validate-samples    run the deterministic acceptance sample corpus
  --samples-root SAMPLES_ROOT
                        sample corpus root (default: the frozen runtime
                        samples)
